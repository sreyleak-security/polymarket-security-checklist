# Pre-Trading Checklist (Polymarket)

Run this BEFORE you deposit or place your first trade.

## Wallet hygiene
- [ ] Trading wallet is SEPARATE from your storage wallet
- [ ] - [ ] Storage key (long-term funds) is on a hardware wallet or never touched a browser
- [ ] - [ ] You wrote the seed phrase on paper. No photos. No cloud notes. No password managers.
- [ ] - [ ] Nobody — ever — has asked for your seed phrase, and nobody ever will legitimately

- [ ] ## Session Keys (scoped signer)
- [ ] - [ ] Trading happens through a Session Key, not your master key
- [ ] - [ ] The scoped signer holds only what you can afford to lose this week
- [ ] - [ ] Session expiry is set (days, not months)

- [ ] ## Account basics
- [ ] - [ ] Signed up via the official domain — # Pre-Trading Checklist (Polymarket)checked character by character (polymarket.com)
- [ ] - [ ] Email on the account is unique, with 2FA on the email itself
- [ ] - [ ] Bookmark the official URL. Navigate by bookmark, never by link from DMs/comments

- [ ] ## Before your first deposit
- [ ] - [ ] Deposit amount = money you can lose without changing your life
- [ ] - [ ] You understand the market you're trading (read official docs first)
- [ ] - [ ] You know how withdrawals work BEFORE you need one

- [ ] ## Red flag scan (30 seconds)
- [ ] - [ ] No one DM'd you a "support" link or an "airdrop"
- [ ] - [ ] The site you're on doesn't ask for seed phrase or private key
- [ ] - [ ] No "connect seed phrase to claim" prompts anywhere
